# Dataset manifest — Checkpoint 04 synthetic examples

- **Name:** Entropy synthetic XOR clusters and random-label control.
- **Source:** Generated locally by `experiments/memorization_vs_generalization.py`.
- **External data:** None downloaded or copied.
- **License/provenance:** Synthetic values generated by the project code; no
  third-party dataset license applies.
- **Configuration:** `configs/cp04_memorization_generalization.json`.
- **Seed:** 2026 for the experiment; the data generators use fixed derived
  seeds for each condition.
- **Splits:** Separate train and held-out test arrays are generated from
  non-overlapping random draws. Structured labels are generated from the XOR
  rule. Random-control labels are sampled independently of inputs.
- **Known limitation:** The random-label control has no underlying rule by
  design. It is a teaching demonstration, not a practical benchmark.
