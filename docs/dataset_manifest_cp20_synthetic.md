# Dataset manifest — Checkpoint 20 synthetic train and validation samples

- **Name:** Generated one-feature linear-rule regression samples.
- **Source:** `experiments/cp20_training_pipeline.py` builds fixed, disjoint
  train and validation grids, then applies `target = slope * input +
  intercept` from the versioned config.
- **External data:** None downloaded or copied.
- **License/provenance:** Values are generated by this project from a
  mathematical rule; no third-party dataset license applies.
- **Configuration:** `configs/cp20_training_pipeline.json`.
- **Seeds:** 2026 for network initialization and 42 for deterministic batch
  shuffling.
- **Splits:** Training inputs cover `[-1.0, 0.5]`; validation inputs cover
  `[0.55, 1.0]`. The ranges do not overlap. Validation loss is measured after
  each epoch and is not used for parameter updates.
- **Known limitation:** This simple synthetic problem checks training and
  resume behavior. It is not a real-world benchmark and has no test split.
