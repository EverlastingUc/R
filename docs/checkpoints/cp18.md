# Checkpoint 18 — Gradient Descent

## Objective

Update network weights and biases with gradient descent and demonstrate a
measurable reduction in training loss.

## What was built

- `src/nn/training.py` provides a full-batch `gradient_descent_step()` using
  the update rule `parameter -= learning_rate * gradient`.
- The step validates the learning rate and stages all new parameters before
  applying them, so invalid updates cannot leave the network half changed.
- `experiments/cp18_gradient_descent.py` runs a seeded, NumPy-only regression
  demonstration from `configs/cp18_gradient_descent.json`.
- The generated dataset provenance is in
  `docs/dataset_manifest_cp18_linear.md`; measured run metadata and loss
  checkpoints are in `reports/cp18_training_metrics.json`.

## Evidence

On the 21-sample synthetic rule `target = 2 * input`, the configured network
started at MSE **1.081216** and reached **6.2836e-27** after 500 full-batch
updates at learning rate `0.01`. Measured losses at epochs 1, 10, and 100 were
1.058971, 0.850388, and 0.0002432. The run used seed 18 and took about 0.058
seconds on the recorded local Windows 11 / Intel CPU environment.

The full test suite passed: **123 passed**. Black and Ruff checks passed.

## How to run it

From the project folder:

```powershell
.venv\Scripts\python.exe experiments\cp18_gradient_descent.py
```

## Limitations

This is a small synthetic regression correctness demonstration. It does not
measure generalization to real-world data or select hyperparameters.
