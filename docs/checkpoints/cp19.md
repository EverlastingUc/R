# Checkpoint 19 — Optimisers

## Objective

Implement SGD, momentum, RMSProp, and Adam, then compare how they reduce the
same objective under a fixed experiment.

## What was built

- `src/nn/optimizers.py` implements all four update rules with shape and finite
  value checks. Stateful optimizers keep per-parameter moving statistics.
- `tests/test_optimizers.py` checks convergence, first-step formulas, shape
  errors, and rejection of non-finite RMSProp state.
- `experiments/cp19_optimizer_comparison.py` evaluates the algorithms on one
  two-parameter quadratic using the same start, target, and 200-step budget.
- Hyperparameters are stored in `configs/cp19_optimizer_comparison.json`;
  problem provenance is in `docs/dataset_manifest_cp19_quadratic.md`.
- The measured loss traces and environment are saved in
  `reports/cp19_optimizer_comparison.json`.

## Evidence

Every optimizer started at loss **17.0**. After 200 updates, measured losses
were:

| Optimizer | Final loss |
|---|---:|
| SGD | 2.0888e-08 |
| Momentum | 7.3231e-09 |
| RMSProp | 0.0 |
| Adam | 0.0030313 |

The loss traces show different early behavior: momentum reached `0.000597` by
step 50, while RMSProp reached `2.798` and Adam reached `3.965` at the same
step. All finished below the starting loss. The full suite passed: **132
passed**. Black and Ruff checks passed.

## How to run it

From the project folder:

```powershell
.venv\Scripts\python.exe experiments\cp19_optimizer_comparison.py
```

## Limitations

This is one convex quadratic with one hyperparameter setting per optimizer. It
shows behavior on this controlled problem; it does not establish a general
ranking for neural-network tasks. Learning rates and loss curves are recorded
in the config and report.
