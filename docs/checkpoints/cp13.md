# Checkpoint 13 — Multiple Neurons

## Objective

Connect multiple neurons into a functioning layer with a configurable neuron
count.

## What was built

`src/nn/layers.py` adds `DenseLayer`. For `m` examples, `n` inputs, and `k`
neurons, it computes `X @ W + b` with shapes `(m, n) @ (n, k) + (1, k)` and
applies a configured activation. Parameters can be supplied for hand checks or
initialized reproducibly with a seed.

## Evidence

- A two-input, three-neuron layer matched independently calculated outputs.
- A configured five-neuron layer returned the expected `(7, 5)` output shape.
- Seeded weights and biases repeat exactly.
- Focused tests: **6 passed**. Full suite after Checkpoint 14: **102 passed**.
- `black .` and `ruff check .` passed.

## Limitations

The layer performs forward calculations only. Parameter updates and training
are covered in Phase 04.
