# LM34 — Assistant-Target-Aware SFT Sampling

## Purpose

Offer a reproducible alternative to uniform sampling when prepared SFT windows
contain different numbers of supervised assistant tokens.

## Strategies

- `uniform-window` (default): every prepared training window has equal sampling
  weight. This preserves the previous training behavior.
- `assistant-token`: each window's sampling weight equals its number of
  supervised next-token targets. A window with twice as many assistant targets
  is twice as likely to be selected.

Sampling uses replacement and the existing checkpointed CPU generator, so
pause/resume preserves the sampling sequence. The selected strategy is stored
in the run configuration and changing it on resume is rejected.

This is a sampling policy, not conversation-level balancing: long conversations
can still contribute more windows. It does not guarantee better model quality;
compare held-out metrics across controlled runs.

## Usage

```powershell
entropy-chat-train .\datasets\prepared --sampling-strategy assistant-token
```

## Verification

The optional PyTorch tests verify exact weights, reject empty/invalid windows,
and retain the existing deterministic resume coverage.

```powershell
python -m pytest tests/test_lm_chat_training.py -q
```
