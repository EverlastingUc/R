# Entropy language-model track — LM-02

## Objective

Turn the LM-01 Transformer into a trainable next-token model using a local
UTF-8 text corpus.

## Implemented

- Ordered train/validation split of the encoded corpus.
- Random contiguous token windows with shifted next-token targets.
- AdamW optimization, gradient clipping, periodic train/validation loss.
- Validation perplexity derived from validation cross-entropy.
- Optional non-overwriting checkpoint containing model, optimizer, architecture,
  tokenizer metadata, and training history.
- CLI entry point: `entropy-train`.

## Run

Install the optional PyTorch dependency and the project:

```powershell
python -m pip install -e ".[llm]"
entropy-train .\data\corpus.txt --steps 1000 --checkpoint .\reports\tiny-model.pt
```

Use a legally obtained, appropriately licensed plain-text corpus. Keep private,
sensitive, copyrighted, or otherwise unauthorized material out of training
datasets. The byte tokenizer is a baseline and makes long sequences; small
experiments should use modest context lengths and batch sizes.

## Limitations

This trainer is single-process and intended for small experiments. It does not
yet implement BPE, packed datasets, streaming/sharded data, mixed precision,
distributed training, checkpoint resume, instruction tuning, or robust
benchmark suites. A lower training loss alone does not establish useful
language understanding; held-out perplexity and task evaluations are required.
