# Checkpoint 15 — Forward Propagation

## Objective

Verify multilayer network outputs against independently calculated reference
results.

## What was built

Added fixed-weight forward-propagation cases for a network with two hidden
layers. The references are calculated directly from the specified matrices and
biases, without calling the network code to produce expected values.

## Evidence

For input `[1, 2]`, the hand calculation gives:

```text
hidden 1 preactivation: [2, 3.5]
hidden 1 output:        [2, 3.5]
hidden 2 preactivation: [-0.5, 6]
hidden 2 output:        [0, 6]
final output:           [-2]
```

The implementation and cached values matched those results. A two-example
batch also matched its independent reference. Focused tests: **3 passed**. Full
suite: **105 passed**. Black and Ruff passed.

## Limitations

The reference cases verify forward calculations, not learned parameter values.
