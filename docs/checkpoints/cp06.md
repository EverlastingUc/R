# Checkpoint 06 — Linear Algebra

## Objective

Practice vectors, matrices, dimensions, transposes, and matrix multiplication.
Implement small operations and compare them with NumPy.

## What was built

`src/nn/linear_algebra.py` implements a dot product, transpose, matrix-vector
product, and matrix multiplication with readable Python loops and lists.
`experiments/cp06_linear_algebra_demo.py` prints a small worked example.

## How to run it

```powershell
.\.venv\Scripts\python.exe -m experiments.cp06_linear_algebra_demo
.\.venv\Scripts\python.exe -m pytest -q
```

## Evidence

- The hand-calculated product of `[[1, 2], [3, 4]]` and `[[5, 6], [7, 8]]`
  was `[[19, 22], [43, 50]]`.
- The demo printed the expected transpose and product.
- The new linear-algebra tests passed: **8 passed**.
- The full test suite passed: **45 passed**.
- The seeded matrix operations also matched NumPy results.

## Limitations

The functions use plain Python lists and loops for learning clarity. NumPy
remains the reference and is the implementation used by the neural network.
