# LM05 — BPE training and inference integration

## Delivered

- Training supports byte and BPE tokenizers.
- BPE merges are learned exclusively from the chronological training partition.
- Model vocabulary size is checked against the selected tokenizer.
- BPE merge tables are embedded in checkpoints, so inference needs no original corpus.
- Checkpoint loading reconstructs and validates the exact tokenizer.
- Generation uses the checkpoint's tokenizer automatically.
- The CLI exposes `--tokenizer bpe|byte` and `--bpe-vocab-size`.
- Existing byte-token checkpoints remain supported.

## Validation

Integration tests train tiny byte and BPE models, save checkpoints, reload them,
and generate output. These are pipeline tests, not evidence of language quality.
