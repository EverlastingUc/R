# Checkpoint 20 — Training Pipeline

## Objective

Train a reproducible model with mini-batches, epochs, shuffling and validation,
then restore a saved training checkpoint.

## What was built

- `src/nn/trainer.py` implements a NumPy `Trainer` with mini-batch updates,
  deterministic seeded shuffling, epoch metrics, and validation loss measured
  after each epoch. The final short batch is included.
- Checkpoints store model parameters, optimizer state, completed epoch count,
  and random-generator state in a versioned `.npz` archive. Loading disables
  pickle. Saving refuses to overwrite an existing checkpoint.
- Optimizers now expose checked state save/restore methods so training resumes
  with the same moving averages and update count.
- `experiments/cp20_training_pipeline.py` runs the configured synthetic task,
  saves a uniquely named report and checkpoint, restores them into a fresh
  model, and checks that predictions match exactly.
- The fixed seeds, architecture, data rule, split ranges, and training settings
  are in `configs/cp20_training_pipeline.json` and
  `docs/dataset_manifest_cp20_synthetic.md`.

## Evidence

Run 004 used 21 training samples, 9 validation samples, batch size 4, and 120
epochs with Adam. Training MSE fell from **0.654636** initially to **0.000862**
at the final epoch. Validation MSE fell from **0.577936** initially to
**0.048382**. The restored checkpoint reported epoch 120 and produced
bit-for-bit identical predictions on the validation inputs.

The run took about 0.65 seconds on the recorded local Windows 11 / Intel CPU
environment. Its full metadata is in
`reports/cp20_training_pipeline_run_003.json`; the saved model/session is
`reports/checkpoints/cp20/cp20-86ddc2482b6c-run-003.npz`.

The full test suite passed: **139 passed**. Black and Ruff checks passed.

## How to run it

From the project folder:

```powershell
.venv\Scripts\python.exe experiments\cp20_training_pipeline.py
```

Each run creates a new numbered report and checkpoint so earlier runs remain
available.

## Limitations

The task is synthetic and small. It verifies the pipeline and exact resume
behavior; it does not evaluate performance on a real-world dataset.
