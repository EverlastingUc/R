# CP23 — Nonlinear Regression Benchmark

## Objective

Verify that Entropy's existing feedforward regression trainer can learn a
nonlinear multivariate function, not only fit a classification boundary.

## Implemented

- A deterministic synthetic dataset with four input features and a nonlinear
  target containing sinusoidal, quadratic, and interaction terms.
- Fixed train/validation/test partitions (70/15/15).
- Input and target normalization fitted on the training partition only.
- A ReLU/tanh multilayer network with a linear output and Adam optimization.
- An evidence report containing training, validation, and held-out test MSE,
  plus test RMSE in the original target units.
- A test that checks deterministic data generation and end-to-end learning.

## Evaluation protocol

The validation partition is monitored during training. The test partition is
not used for gradient updates or model selection. The benchmark is deliberately
offline and deterministic so it can run in CI without external dataset access.

## Limitations

This is a synthetic regression benchmark. It verifies numerical learning and
the existing training path; it is not evidence of real-world forecasting,
reasoning, or language-model ability. A future real-world regression checkpoint
should use a documented public dataset and a leakage-safe chronological split.
