# LM18 — Conversation context-window management

## Objective

Prevent a long conversation from silently losing its system instruction or
latest user turn when the prompt exceeds the model's context length.

## Packing policy

The chat inference path builds token IDs message by message, matching the
header/content tokenization used by conversation fine-tuning.

1. Reserve room for BOS, the assistant response prefix, and the latest user
   header plus at least one content token.
2. Preserve the first system message when it can fit. If the system message and
   latest user turn do not both fit, retain the system header and a bounded
   initial portion of its content using a priority allocation.
3. Always preserve the latest user header and trailing user content.
4. Add older messages in reverse chronological order only when each complete
   message fits. Stop at the first older message that cannot fit; do not keep
   disconnected fragments.
5. Restore chronological order before generation.

If the configured context is too small even for the required chat structure,
the helper raises a clear error rather than sending a malformed prompt.

## API

`build_chat_input_ids(tokenizer, messages, context_length=...)` exposes the
packing behavior for byte and BPE tokenizers. `stream_chat_response` uses it
automatically, so the existing CLI and complete-response API benefit without
new flags.

## Validation

Tests use a byte tokenizer to verify that the system instruction and latest
user turn survive truncation, that complete recent history is retained when it
fits, that old turns are removed before the active user request, and that
contexts too small for the role headers are rejected.

## Limitations

This is a deterministic truncation policy, not a learned memory system. It
does not summarize removed turns, retrieve facts from older conversation
history, rank messages by relevance, or provide persistent memory. Very long
system instructions are truncated after their header and an initial segment;
very long user messages retain their trailing content.
