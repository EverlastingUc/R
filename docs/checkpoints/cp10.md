# Checkpoint 10 — Optimisation Mathematics

## Objective

Implement gradient descent and show how the learning rate affects convergence
on a function whose minimum is known.

## What was built

`src/nn/optimization.py` implements vector-valued gradient descent. At each
step it subtracts the learning rate times the gradient, records the objective,
and checks parameter and gradient shapes and finite values.

The experiment minimizes `f(x) = (x - 3)^2` from `x = -5` for 20 steps.

## How to run it

```powershell
.\.venv\Scripts\python.exe -m experiments.cp10_gradient_descent_demo
.\.venv\Scripts\python.exe -m pytest -q
```

## Evidence

| Learning rate | Final parameter | Initial loss | Final loss |
|---:|---:|---:|---:|
| 0.1 | 2.907766 | 64 | 0.009 |
| 0.5 | 3.000000 | 64 | 0.000 |
| 1.1 | -303.700799 | 64 | 94,065.380 |

The first two rates converged; the oversized rate diverged. Focused tests:
**7 passed**. Full suite: **79 passed**. Black and Ruff passed.

## Limitations

This one-dimensional quadratic has a simple known minimum. Learning rates that
work here are not automatically appropriate for a neural network.
