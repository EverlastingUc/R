# CP22 — Softmax Classification Training

## Objective

Extend Entropy's from-scratch NumPy network from regression-only training to
multiclass classification using categorical cross-entropy and softmax.

## Implemented

- Stable categorical cross-entropy from logits.
- Softmax-cross-entropy backpropagation with the fused
  (probabilities minus one-hot targets) gradient at the output layer.
- Mini-batch classification training with deterministic shuffling and the
  existing stateful optimizers (SGD, Momentum, RMSProp, and Adam).
- Full-split training and validation loss and accuracy after each epoch.
- Probability and integer-class prediction methods.
- Input, label-range, one-hot-target, and output-activation validation.

## Iris experiment scaffold

- `src/nn/uci_iris.py` downloads and validates the official UCI archive,
  creates deterministic stratified partitions, and fits normalization on
  training data only.
- `experiments/cp22_iris_classifier.py` trains the classifier, monitors the
  validation split, evaluates the test split only after training, and writes a
  non-overwriting JSON evidence report.
- `tests/test_uci_iris.py` covers deterministic splits, class balance,
  train-only normalization, source metadata, corrupt archives and unsafe paths.

The live UCI download and resulting Iris metrics have not yet been executed.
