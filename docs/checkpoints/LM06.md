# LM06 — Reproducible corpus preparation

## Goal

Turn a directory of UTF-8 text documents into deterministic, leakage-aware
training inputs for Entropy's experimental language model.

## Implemented

- Recursively discovers .txt files in stable path order, or accepts one
  .txt file directly.
- Strictly decodes UTF-8; malformed files fail with a source-specific error.
  Text is not silently normalized or rewritten.
- Records empty/whitespace-only files instead of treating them as training data.
- Removes exact byte-identical duplicates before splitting and records their
  additional source paths.
- Splits at the document level with a seeded shuffle. Validation/test counts
  use ceiling for nonzero requested fractions when enough documents exist,
  while preserving at least one training document.
- Fits byte-level BPE exclusively on the training split. The byte tokenizer
  remains available as a no-training baseline.
- Writes tokenizer metadata, a SHA-256 tokenizer fingerprint, per-split JSONL
  token-ID files, and a JSON provenance manifest.

## Run

Install the optional language-model dependencies only when training a model:

    python -m pip install -e ".[llm]"
    entropy-prepare-corpus ./my-text-corpus ./prepared-corpus --tokenizer bpe --vocab-size 2000 --seed 42

The input can be a single .txt file or a directory containing .txt files.
The output directory contains:

- manifest.json — source hashes, split assignments, duplicate/skip counts,
  tokenizer configuration and fingerprint, document/token counts.
- tokenizer.json — the BPE merge table or byte-tokenizer metadata.
- train.jsonl, validation.jsonl, test.jsonl — one document per line,
  with source, content hash, tokenizer fingerprint and token IDs.

For very small corpora, a requested validation/test split is created only when
at least one training document can be retained. A one-document corpus therefore
produces a training-only split. Use a larger corpus for meaningful evaluation.

## Integrity boundaries

This checkpoint detects exact duplicate files, not paraphrases or near-duplicates.
The manifest records local source paths; do not publish it if those paths are
private. The pipeline does not download datasets, scrape websites, or claim that
a corpus is licensed or suitable for model training. Verify dataset rights and
remove personal or sensitive data before using external corpora.

## Validation

tests/test_lm_corpus.py covers deterministic output, duplicate removal,
training-only tokenizer fitting, provenance, empty files, malformed UTF-8,
invalid split settings, single-file inputs, output-directory exclusion and
document-level split separation.
