# Checkpoint 14 — Multilayer Network

## Objective

Build and execute a feedforward network with at least two hidden layers.

## What was built

`src/nn/network.py` assembles configurable dense layers. A size sequence such as
`[2, 4, 3, 1]` defines two inputs, hidden layers of four and three neurons, and
one output. Each connection has its own activation. A forward call can also
return the inputs, preactivations, and outputs cached at every layer for later
gradient calculations.

## Evidence

- A seeded `[2, 4, 3, 1]` network successfully processed a batch and returned
  shape `(5, 1)`.
- Tests verify the two hidden layers, activation/cache shapes, reproducible
  parameters, and invalid architecture rejection.
- Focused tests: **4 passed**. Full suite: **102 passed**.
- `black .` and `ruff check .` passed.

## Limitations

This checkpoint verifies forward execution. It does not yet train the
multilayer network.
