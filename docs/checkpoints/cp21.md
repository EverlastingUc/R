# Checkpoint 21 — Dataset Engineering

## Objective

Create a documented and reproducible pipeline for Entropy's first real
classification and regression datasets.

## Approved sources

The owner approved Option B on 2026-11-18:

- UCI Iris (ID 53), CC BY 4.0, attributed to R. A. Fisher.
- UCI Bike Sharing (ID 275), CC BY 4.0, attributed to Hadi Fanaee-T.

The sources, citations, feature definitions, target definitions, licence,
attribution and split rules are recorded in
docs/dataset_manifest_cp21.md.

## Implementation

- src/nn/datasets.py implements bounded UCI-only HTTPS acquisition, safe
  ZIP member reading, source hashing, strict parsing, deterministic
  stratified Iris splits, chronological whole-day Bike Sharing splits,
  train-only standardisation and non-overwriting NumPy/JSON persistence.
- Bike Sharing's casual and registered columns are excluded because
  they directly sum to the cnt target. instant and dteday are also
  excluded from the model feature matrix.
- configs/cp21_dataset_pipeline.json records the seed, split fractions
  and output paths.
- experiments/cp21_dataset_pipeline.py downloads and prepares both
  datasets and writes provenance sidecars.
- tests/test_datasets.py adds deterministic, network-free tests for
  stratification, reproducibility, temporal split isolation, target leakage,
  parsing failures, constant columns, persistence and download-host checks.
- The existing .gitignore already excludes the data/ directory, so raw
  source archives and prepared arrays stay out of Git.

## Reproduction

From the repository root:

    python -m pytest -q tests/test_datasets.py
    python -m experiments.cp21_dataset_pipeline

The second command writes source archives to data/raw/ and prepared arrays
plus JSON provenance to data/processed/. Existing prepared outputs are
never overwritten.

- CP21 remains **in progress** until CI passes and the real-data pipeline has
  been run successfully.

## Limitations

- Iris is a small teaching benchmark and cannot establish broad
  classification capability.
- Bike Sharing is one city-specific historical demand dataset. This
  checkpoint does not claim general mobility forecasting skill.
- No model is trained or tuned here. Classification and regression model
  experiments belong to CP22 and CP23, respectively.
