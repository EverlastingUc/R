# LM23 — Checkpoint and inference profiling

## Objective

Measure the current checkpoint and runtime before choosing a larger model,
context window, or deployment target.

## Run

```powershell
entropy-profile .\runs\assistant.pt --prompt "Explain gravity simply." --max-new-tokens 64 --batch-size 1 --warmup-steps 2 --device cpu --output .\reports\profile.json
```

Use `--device cuda` on a CUDA-enabled PyTorch installation. The report can
also be printed without writing a file by omitting `--output`.

## Report

The JSON report includes:

- Checkpoint SHA-256 and exact file size.
- Architecture dimensions, tokenizer type, unique parameter count, parameter
  storage bytes, and parameter dtype.
- PyTorch version, selected device, device name, batch size, prompt length,
  warmup count, and generation settings.
- Independent prefill latency, first-token latency, mean and median subsequent
  decode-step latency, and total generation time.
- Generated token count, tokens per second, decode steps per second, and peak
  allocated CUDA memory when running on CUDA.

The profiler preserves the caller's PyTorch CPU and CUDA RNG states. It uses
greedy top-k-one decoding and the model's cached generation path. Warmup runs
are excluded from the measured generation interval.

## Interpretation

Compare profiles only when the checkpoint, prompt, context, batch size, device,
PyTorch version, and generation length are comparable. Prefill latency is a
separate full-prompt forward measurement. First-token latency includes the
generation stream's own prefill and initial sample. Subsequent step latency
includes cached decoding and token sampling.

## Limitations

This is a lightweight local profiler, not a statistically rigorous hardware
benchmark. It performs one measured generation pass after warmup and does not
estimate FLOPs, report system RAM, benchmark training throughput, or isolate
kernel-level GPU time. GPU readings are device- and driver-dependent. Use
multiple runs and hardware-specific profilers before making production capacity
or cost estimates.
