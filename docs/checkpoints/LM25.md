# LM25 — RoPE sliding-window attention

## Objective

Add an optional local-attention window to RoPE models. Each token attends only
to itself and the preceding `attention_window - 1` tokens. The default remains
full causal attention.

## Configuration

```python
from entropy_lm.model import TransformerConfig

config = TransformerConfig(
    position_encoding="rope",
    attention_window=512,
)
```

Both `entropy-train` and `entropy-chat-train` expose
`--attention-window 512`. Omit the option for full causal attention.

The window must be an integer from one through the configured context length.
This first implementation requires RoPE; learned absolute-position models
reject a sliding-window setting rather than silently changing their positional
semantics.

## Implementation

The full-sequence path builds a causal local mask and passes it to PyTorch
scaled-dot-product attention. Cached prefill and incremental decoding apply
the same lower-bound mask to query/key positions. The existing KV cache and
context-length limits remain intact. When generation reaches the context
limit, the existing sliding-context rebuild keeps the most recent context
tokens and recomputes their cache.

## Validation

Tests compare the local mask path with a reference execution, compare full
forward logits against chunked cached prefill and decode, exercise generation
past the context limit, validate configuration errors, and train/load both
pretraining and SFT checkpoints with a configured window.

## Trade-offs and limitations

For a sequence length L and window W, attention score work can scale with
approximately L×W instead of L², although this implementation currently uses
a dense boolean mask and therefore does not guarantee sparse-kernel execution
or a proportional wall-clock speedup. The KV cache still stores up to the
configured context length. A local attention model is a different architecture
from a full-attention model and must be trained with the intended window;
enabling it only at inference changes model behavior. It does not extend the
maximum context length.
