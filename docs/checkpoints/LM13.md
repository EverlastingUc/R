# LM13 — Conversation-aware local chat inference

## Objective

Turn an inference-compatible Entropy checkpoint into a local interactive
conversation loop. The runtime must format role-tagged history the same way as
the LM11 supervised dataset and stop generation when the tokenizer's EOS token
is emitted.

## CLI

Install the optional PyTorch dependency and use a trained SFT checkpoint:

```powershell
python -m pip install -e ".[llm]"
entropy-chat .\runs\assistant.pt
```

Options include `--system-prompt`, `--max-new-tokens`, `--temperature`,
`--top-k`, and `--device`. The terminal accepts `/reset` to clear the
conversation history and `/exit` to quit.

The loop stores conversation history in memory only. It does not create user
accounts, persistent memory, retrieval, or multi-user sessions.

## Prompt and generation behavior

The formatter serializes system, user, and assistant messages as
`<|role|>\ncontent\n` and appends an assistant prefix. It rejects empty
messages, unsupported roles, histories without a user message, or histories
that do not end with a user turn.

The prompt is tokenized with BOS and clipped to the model's context length.
Generation uses the tokenizer stored in the checkpoint. The Transformer can
now stop when the configured EOS ID is emitted; batched generation also keeps
already-finished sequences at EOS until all sequences are finished. The chat
wrapper decodes only newly generated tokens, not the prompt.

## Validation

Tests cover message formatting, invalid conversation endings, a generated
response from a locally fine-tuned test checkpoint, and deterministic EOS
stopping. Existing text generation remains compatible because EOS stopping is
optional.

## Limitations

A chat interface is not evidence of assistant quality. The model still needs
large-scale pretraining, real conversational instruction tuning, rigorous
capability and safety evaluations, and resource-aware serving. The current
chat loop has no tool calling, web retrieval, streaming tokens, persistent
memory, multimodal support, authentication, or production API.
