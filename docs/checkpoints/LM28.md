# LM28 — Prepared Conversation Dataset Integrity

## Purpose

Add a read-only integrity check between raw conversation preparation and model
training. It verifies tokenizer fingerprints, manifest metadata, split counts,
conversation hashes, split assignments, token ranges, assistant-only label
alignment, and the presence of supervised targets.

## Usage

```powershell
entropy-check-chat-data .\\datasets\\prepared-chat
```

The command fails with a specific error when metadata or tokenized records do
not agree. A successful report includes aggregate split, token, and target
counts. It never prints conversation text or token sequences and never
modifies the prepared dataset.

## Recommended workflow

1. Run `entropy-audit-chat-data` against the raw JSONL corpus.
2. Review malformed records, duplicates, and structural warnings.
3. Run `entropy-prepare-chat` to create train, validation, and test splits.
4. Run `entropy-check-chat-data` before SFT training.
5. Keep the test split untouched until final evaluation.

This validates structural integrity and split isolation, not semantic quality,
factual correctness, safety, or privacy. It cannot establish that a corpus is
suitable for training simply because the check passes.
