# LM21 — Nucleus sampling and repetition controls

## Objective

Expose two common decoding controls consistently across the model API, local
chat interface, and reference-based chat benchmark.

## Controls

- `top_p` (default `1.0`): nucleus sampling. Sort candidate tokens by
  probability and retain the smallest highest-probability prefix whose
  cumulative probability reaches the requested threshold. The first token is
  always retained. A value of `1.0` disables nucleus filtering.
- `repetition_penalty` (default `1.0`): for token IDs already present in the
  recent context window, divide positive logits by the penalty and multiply
  negative logits by it. Values greater than one discourage repetition;
  values between zero and one encourage it. A value of `1.0` disables the
  adjustment.

Filtering order is repetition penalty, top-k, then top-p, followed by softmax
and multinomial sampling. Repetition tracking is bounded to the model's current
context window, matching the context available to cached attention.

## APIs and CLI

`CausalLanguageModel.generate` and `generate_stream`, the chat Python
functions, and `entropy-chat` accept `top_p` and
`repetition_penalty`. The benchmark command accepts the same controls and
writes both values into the report's generation metadata.

Example:

```powershell
entropy-chat .\runs\assistant.pt --temperature 0.8 --top-k 40 --top-p 0.9 --repetition-penalty 1.1
```

Defaults preserve prior sampling behavior.

## Validation

Tests verify that nucleus filtering retains the probability-mass prefix,
repetition penalty adjusts positive and negative repeated-token logits using
the specified rule, default values leave logits unchanged, invalid values are
rejected, and the controls reach the chat and benchmark paths.

## Limitations

These controls modify token selection only; they do not improve the learned
model, factuality, reasoning, instruction following, or safety. Aggressive
penalties can damage grammar or prevent legitimate repetition. Top-p scores
are decoding parameters, not model-quality metrics.
