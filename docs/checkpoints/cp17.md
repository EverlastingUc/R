# Checkpoint 17 — Backpropagation

## Objective

Compute dense-network weight and bias gradients with the chain rule, then compare
every analytical gradient with centered finite differences.

## What was built

- `src/nn/backprop.py` computes mean-squared-error gradients for every dense
  layer, including row-wise softmax derivatives.
- `src/nn/gradcheck.py` provides a reusable `gradient_check()` utility using
  centered differences with `epsilon=1e-6` and a documented relative-error
  tolerance of `1e-5`.
- `tests/test_backprop.py` checks all six supported activations in a network
  with two hidden layers, finite gradients, and parameter restoration.
- `.github/workflows/tests.yml` runs the full pytest suite on pushes and pull
  requests, so the gradient checks remain part of CI.

## Evidence

The six activation checks compared 23 parameters each. Maximum relative errors
were:

| Activation | Maximum relative error |
|---|---:|
| identity | 5.129e-09 |
| sigmoid | 1.549e-06 |
| tanh | 7.582e-09 |
| ReLU | 5.129e-09 |
| leaky ReLU | 5.129e-09 |
| softmax | 1.077e-06 |

All were below the `1e-5` tolerance. The full test suite passed: **121 passed**.
Black and Ruff checks passed after formatting and removing one unused import.

## Limitations

Backpropagation currently supports dense layers and MSE. Other layer types and
loss functions need their own derivatives and gradient checks before use.
