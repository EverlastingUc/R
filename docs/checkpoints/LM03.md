# Entropy language-model track — LM-03

## Objective

Make a trained LM-02 checkpoint usable for local autoregressive generation.

## Implemented

- Weights-only checkpoint loading with architecture and state-dictionary checks.
- Explicit evaluation mode for inference.
- Prompt encoding and autoregressive generation.
- Replacement decoding for incomplete UTF-8 byte sequences emitted by an
  untrained or partially trained byte-level model.
- CLI entry point: `entropy-generate`.

## Run

```powershell
entropy-generate .\reports\tiny-model.pt --prompt "Once upon a time" --max-new-tokens 120
```

The checkpoint must have been created by the LM-02 training pipeline. Generation
quality depends entirely on corpus quality, model size, training duration, and
evaluation; an untrained model will produce largely random text.

## Security and limitations

The loader uses PyTorch's weights-only deserialization mode and validates the
checkpoint structure before loading weights. Only load checkpoints from sources
you trust. This prototype does not yet support tokenizer merges, chat templates,
instruction tuning, sampling stop sequences, or production serving.
