# Checkpoint 08 — Probability and Statistics

## Objective

Calculate probability, expectation, variance, entropy, and conditional
probability, and run a reproducible sampling experiment.

## What was built

`src/nn/probability.py` normalizes probability weights, computes expected
value and variance, calculates Shannon entropy in bits, evaluates a
conditional probability from a joint table, and samples categories with a
fixed seed. `experiments/cp08_probability_demo.py` runs a 20,000-sample
experiment for probabilities `[0.25, 0.75]`.

## How to run it

```powershell
.\.venv\Scripts\python.exe -m experiments.cp08_probability_demo
.\.venv\Scripts\python.exe -m pytest -q
```

## Evidence

- Hand-calculated expected value: `0.750`.
- Hand-calculated variance: `0.1875` (printed as `0.188`).
- Entropy: `0.811` bits.
- Seeded empirical frequencies over 20,000 samples: `[0.2522, 0.7478]`.
- Focused tests: **10 passed**. Full suite: **64 passed**.
- `black .` and `ruff check .` passed.

## Limitations

Sampling frequencies vary with the seed and sample count. The experiment
illustrates the law of large numbers; it is not evidence about real-world
data.
