# Checkpoint 07 — Calculus

## Objective

Calculate derivatives, partial derivatives, and the chain rule for functions
used by a neural network.

## What was built

`src/nn/calculus.py` contains a stable sigmoid, its derivative, mean squared
error and its derivative, and the weight/bias derivatives for one sigmoid
neuron. The neuron loss uses the chain rule:

```text
L = (p - y)^2
dL/dz = 2(p - y) × p(1 - p)
dL/dw = x × dL/dz
dL/db = dL/dz
```

`experiments/cp07_calculus_demo.py` prints the sigmoid derivative and the
neuron's weight and bias gradients for a small example.

## How to run it

```powershell
.\.venv\Scripts\python.exe -m experiments.cp07_calculus_demo
.\.venv\Scripts\python.exe -m pytest -q
```

## Evidence

- Hand-calculated sigmoid and MSE cases passed.
- The neuron weight and bias gradients agreed with centered finite differences
  within the documented test tolerance (`rtol=1e-6`, `atol=1e-8`).
- Focused tests: **9 passed**. Full suite: **54 passed**.
- `black .` and `ruff check .` passed.

## Limitations

The gradient calculation is for one sigmoid neuron with one squared-error
target. Reusable multi-layer gradient checking is Checkpoint 17.
