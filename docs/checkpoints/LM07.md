# LM07 — Stable training controls

## Goal

Make small decoder-only Transformer experiments easier to train, compare and
reproduce without requiring a large GPU batch.

## Implemented

- Linear learning-rate warmup followed by cosine decay to a configurable
  minimum learning-rate ratio.
- Gradient accumulation. The configured batch size remains the microbatch size;
  effective batch size is microbatch size multiplied by accumulation steps.
- Gradient clipping at a global norm of 1.0.
- Periodic training/validation loss, validation perplexity, learning rate and
  mean microbatch-loss reporting.
- Optional early stopping after a configured number of consecutive evaluations
  without validation-loss improvement.
- Best-validation checkpoint selection, including model, optimizer and
  scheduler state, training configuration, corpus SHA-256, tokenizer metadata
  and metric history.
- Atomic checkpoint replacement so an interrupted write does not leave a
  partially written final checkpoint.
- Validation of training parameters before model construction.

## Example

    entropy-train ./prepared-corpus.txt --steps 1000 --batch-size 8 --gradient-accumulation-steps 4 --warmup-steps 50 --minimum-learning-rate-ratio 0.1 --early-stopping-patience 5 --checkpoint ./reports/entropy-best.pt

The effective batch size in this example is 32. The model still processes
microbatches of 8 sequences at a time.

For short experiments, the CLI chooses a warmup of at most 50 optimizer steps
and always leaves at least one post-warmup step. The Python API defaults to no
warmup unless warmup_steps is supplied.

## Important limitations

The current trainer still accepts one text string and creates a chronological
character-level train/validation split. For document-level splits and corpus
provenance, use the LM06 corpus-preparation pipeline first; a later milestone
will connect its JSONL token datasets directly to the trainer. This checkpoint
does not yet implement exact training resume, distributed training, mixed
precision, or instruction tuning.

A best-validation checkpoint is a research artifact, not evidence of general
assistant capability. Meaningful language quality requires a large, legally
usable corpus, longer training, evaluation and human review.
