# Entropy language-model track — LM-01

## Why this milestone exists

The existing Entropy feedforward network learns fixed-size numeric mappings. A
conversational language model needs a different objective: predict the next
token in a sequence. LM-01 introduces the first language-model building blocks.

## Implemented

- A UTF-8 byte tokenizer with a 258-token vocabulary (256 byte values, BOS, EOS).
- A decoder-only Transformer with learned token/position embeddings, causal
  self-attention, feed-forward blocks, layer normalization, and tied input/output
  embeddings.
- Next-token cross-entropy loss and autoregressive sampling with temperature
  and optional top-k filtering.
- PyTorch is an optional extra; the existing NumPy research track remains
  installable without it.

## Install and smoke-test

```powershell
python -m pip install -e ".[llm]"
```

The initial tokenizer is deliberately simple. It is lossless and language
agnostic, but byte-level sequences are longer than subword tokenization. A
trained BPE tokenizer, packed text dataset, training loop, validation
perplexity, checkpointing, and generation evaluation are subsequent milestones.

## Important limitations

This is a small educational architecture, not a pretrained assistant. It has
no learned language knowledge until trained on a suitable corpus. Its default
configuration is intentionally modest and is not comparable in capability to
ChatGPT or Claude. Training at those scales requires substantial data,
accelerators, distributed systems, and safety/evaluation work.
