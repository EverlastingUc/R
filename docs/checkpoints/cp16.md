# Checkpoint 16 — Loss Functions

## Objective

Implement mean squared error and cross-entropy, and verify them against known
numerical examples.

## What was built

`src/nn/losses.py` implements MSE and its prediction gradient, binary
cross-entropy, categorical cross-entropy for probabilities, and stable
categorical cross-entropy directly from logits. It also provides the
softmax-cross-entropy gradient with respect to logits.

## Evidence

- Hand-calculated MSE, MSE gradient, binary cross-entropy, and categorical
  cross-entropy checks passed.
- Logits `[1000, 1001, 999]` produced a finite cross-entropy matching the
  stable log-sum-exp reference.
- Focused tests: **8 passed**. Full suite: **113 passed**.
- `black .` and `ruff check .` passed.

## Limitations

Categorical cross-entropy expects one-hot target rows. Integer class labels can
be added later if a dataset pipeline needs them.
