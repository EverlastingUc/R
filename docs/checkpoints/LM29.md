# LM29 — Instruction Dataset Ingestion

## Purpose

Normalize three explicit JSONL record shapes into the conversation schema already
consumed by `entropy-prepare-chat`:

- `{"messages": [...]}` for existing multi-turn conversations.
- `{"prompt": "...", "completion": "..."}` for prompt/response pairs.
- `{"instruction": "...", "input": "...", "output": "..."}` for instruction datasets.

An optional non-empty `system` string is accepted for prompt/response and
instruction records. For instruction records, a non-empty input is appended to
the instruction with a blank line separator.

## Usage

```powershell
entropy-normalize-instructions .\datasets\raw-instructions.jsonl .\datasets\normalized-chat.jsonl
entropy-audit-chat-data .\datasets\normalized-chat.jsonl --report .\reports\normalized-audit.json
entropy-prepare-chat .\datasets\normalized-chat.jsonl .\datasets\prepared-chat
entropy-check-chat-data .\datasets\prepared-chat
```

## Data integrity behavior

- UTF-8 and JSON are validated strictly.
- Unsupported or incomplete schemas fail with a line-specific error.
- Blank lines are counted and skipped.
- Output is written to a temporary file and atomically replaced only after all
  records validate; an existing output remains intact on failure.
- No source record is silently discarded or heuristically reinterpreted.
- The command prints aggregate counts, not conversation content.

Normalization does not establish factuality, safety, privacy, licensing, or
instruction quality. Review data rights and content before training.
