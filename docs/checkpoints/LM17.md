# LM17 — Reference-based chat benchmark

## Objective

Measure generated assistant responses on a benchmark dataset that is separate
from the conversation data used for pretraining or supervised fine-tuning.
LM14 measures next-token likelihood; LM17 adds prompt-level generation results.

## Dataset format

Use UTF-8 JSONL with one case per line:

```json
{"id":"addition-001","messages":[{"role":"user","content":"What is 2 + 2?"}],"reference":"4","must_include":["4"],"must_not_include":["5"]}
{"id":"capital-001","messages":[{"role":"user","content":"What is the capital of France?"}],"reference":"Paris"}
```

Each case requires a unique non-empty `id`, a valid chat history ending in a
user message, and a non-empty reference answer. `must_include` and
`must_not_include` are optional lists of non-empty phrases.

Keep this benchmark independent from training and model-selection data. Store
the dataset with version control or other provenance so checkpoint comparisons
use exactly the same cases.

## Run

```powershell
entropy-benchmark-chat .\runs\assistant.pt .\chat-benchmark.jsonl --output .\reports\lm17.json
```

The default decoding uses `top_k=1` and seed zero for repeatable greedy
selection. Options include `--max-new-tokens`, `--temperature`, `--top-k`,
`--seed`, `--device`, and `--output`. The evaluator restores the caller's
PyTorch CPU and CUDA random-number-generator states after evaluation.

## Reported metrics

- Normalized exact-match rate (Unicode NFKC, case-folded, whitespace-collapsed).
- Mean token F1 using Unicode word tokens and multiset overlap.
- Required-phrase case pass rate.
- Prohibited-phrase case violation rate.
- Per-case reference, generated response, and scores.
- Checkpoint and benchmark dataset SHA-256 hashes.
- Generation settings and seed.

## Interpretation and limitations

These are transparent, reproducible text-comparison metrics. Exact match is
strict, token F1 is lexical rather than semantic, and phrase checks only test
consecutive normalized Unicode word-token sequences. They cannot determine whether a paraphrase is
correct, detect subtle hallucinations, assess reasoning, judge code quality,
measure safety, or replace human review. Do not present these scores as a
ChatGPT-equivalence or general intelligence measure.

Use a curated benchmark with task diversity, adversarial cases, unanswerable
questions, factuality checks, and human-reviewed references before drawing
capability conclusions.
