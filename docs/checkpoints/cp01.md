# Checkpoint 01 — Artificial Intelligence Fundamentals

## Goal

Explain AI, machine learning, deep learning, and neural networks, and show how
they relate. The examples below use established definitions and established
facts, rather than new project claims.

## The four ideas

### Artificial intelligence (AI)

AI is the broad field of building computer systems that perform tasks that
usually require abilities such as perception, reasoning, language use, or
decision making. A route planner that searches possible roads is an AI system;
it does not need to be a neural network.

**Established example:** A chess program can choose moves by searching and
scoring possible future positions.

### Machine learning (ML)

Machine learning is one way to build AI. Instead of writing every decision as a
fixed rule, we give a learning algorithm examples or feedback and let it fit
parameters that help with the task.

**Established example:** An email classifier can learn from messages labelled
“spam” and “not spam,” then predict a label for a new message.

### Deep learning

Deep learning is a kind of machine learning that uses neural networks with
multiple layers of learned calculations. “Deep” refers to the sequence of
layers, not to human-like understanding.

**Established example:** A multilayer image classifier can learn intermediate
features from pixel values and use them to predict an image category.

### Neural network

A neural network is a model made of connected calculations. Each connection
has a weight. During training, an optimisation method adjusts weights so the
model's answers better match the examples. Networks can have one layer or many;
a network is not automatically “deep” just because it is neural.

**Established example:** Entropy's first model is a small network with two
inputs, one hidden layer, and one output. It will learn the XOR truth table.

## How they fit together

```text
AI
└── Machine learning (one approach to AI)
    └── Deep learning (machine learning with multi-layer neural networks)
```

A neural network is a model family used in machine learning. A sufficiently
layered network is a deep-learning model. AI is broader than either one.

## What “training Entropy” means

Training means showing Entropy examples with known answers. The network makes
a prediction, compares it with the answer, and calculates a loss: a number
that summarizes how wrong its predictions were. Backpropagation calculates
how the weights contributed to that loss; gradient descent makes small weight
changes in the direction expected to reduce it. Repeating this over many
examples is the learning process.

We keep three kinds of data separate:

- **Training examples** are used to adjust the weights.
- **Validation examples** help us choose settings while building the model.
- **Test examples** are held aside for the final, less-biased check.

For the first tiny XOR lesson, the four possible input pairs are the whole
problem, so the demonstration will use them to show fitting. A later experiment
will use separate held-out examples to demonstrate generalization and
memorization.

## Limitations

These definitions are introductory. They do not claim that a small XOR network
is a general-purpose AI system or that a good training score alone proves a
model will work on new data.
