# Checkpoint 21 — Dataset candidates awaiting owner approval

No candidate below has been downloaded or used for Phase 05. The project
instructions require owner approval before data use.

## Option A — Project-generated synthetic classification and regression

- **Classification provenance:** Entropy would generate small labeled clusters
  from explicit mathematical rules in a versioned NumPy script and seed.
- **Regression provenance:** Entropy would generate features and targets from
  an explicit formula plus seeded noise, also in a versioned script.
- **License:** No third-party dataset license applies because the values are
  generated by this project. The generator and parameters would be documented.
- **Trade-off:** Fastest and clearest for learning the training pipeline, but
  results would only demonstrate behavior on synthetic tasks.

## Option B — UCI Iris classification and UCI Bike Sharing regression

- **Iris classification provenance:** Fisher's Iris dataset, distributed by
  the UCI Machine Learning Repository; 150 plant samples, four measurements,
  and three classes. UCI lists the license as Creative Commons Attribution 4.0
  International (CC BY 4.0), DOI `10.24432/C56C76`.
- **Bike regression provenance:** Capital Bikeshare hourly/daily rental counts
  from 2011–2012 with weather and calendar attributes; UCI lists 17,389 hourly
  records and the license as CC BY 4.0, DOI `10.24432/C5W894`.
- **Sources:** [UCI Iris](https://archive.ics.uci.edu/dataset/53/iris) and
  [UCI Bike Sharing](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset).
- **Attribution:** The project would credit R. A. Fisher for Iris and Hadi
  Fanaee-T for Bike Sharing, and retain the UCI dataset citations and licenses
  in each manifest.
- **Leakage controls:** Iris splits would preserve class representation. Bike
  records would be split by time, and `casual`/`registered` would be excluded
  when predicting `cnt` because they sum to the target.
- **Trade-off:** Uses real data and teaches attribution and time-aware splits;
  the bike task needs extra preprocessing and stricter leakage checks.

## Approval needed

Choose Option A or Option B before CP21 downloads or uses any data. No data
